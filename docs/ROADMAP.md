# 다음 개선 후보

공개 준비 점검에서 확인한 후속 작업입니다. 완료한 기능과 구분합니다.

1. **파일별 재생 가능 여부 판정:** 현재 클립의 대표 파일 헤더로 암호화를 추정합니다. 평문/암호화가 섞이면 정상 파일도 가려질 수 있어 파일별 상태와 실패 카메라 제외가 필요합니다.
2. **실제 파일 길이 사전 확인:** 현재 구간을 열 때 길이를 갱신합니다. 읽기 비용을 제한하는 메타데이터 큐를 도입하면 전체 시간 막대의 예상 구간을 줄일 수 있습니다.
3. **여러 파일을 가로지르는 A/B 저장:** 현재 저장은 한 파일 구간 안에서 가능합니다. 긴 사건의 일부를 한 파일로 내보내려면 별도의 인코딩/병합 설계가 필요합니다.
4. **카메라 선택 재생:** 카메라가 많은 차량에서 필요한 영상만 디코딩하도록 선택 기능을 넣어 저사양 PC의 부하를 줄일 수 있습니다.
5. **독립 GPS 기록 가져오기:** GPX 등의 연속 위치 데이터를 사용자가 제공할 때 실제 이동 경로를 연동할 수 있습니다. 현 이벤트 좌표만으로는 경로를 복원하지 않습니다.
